### 📦 Level 6 – Data Structures and Algorithm Projects

#### Overview

This repository contains a collection of small projects built to demonstrate practical understanding of core Data Structures in JavaScript.

Each project focuses on **when and why** a specific data structure should be used, not just how it works.

---

### 🧠 Projects Included

1️⃣ **Task Scheduler (Queue – FIFO)**
Simulates a task processing system where tasks are handled in the order they are added.

* Data Structure: Queue
* Concept: First In, First Out
* Use case: Background jobs, task processors

---

2️⃣ **Undo / Redo System (Stack)**
Implements undo and redo functionality similar to text editors.

* Data Structure: Stack
* Concept: Last In, First Out
* Use case: Editors, history tracking

---

3️⃣ **Unique Visitor Tracker (Set)**
Tracks unique visitors while automatically ignoring duplicates.

* Data Structure: Set
* Concept: Uniqueness enforcement
* Use case: Analytics, authentication tracking

---

4️⃣ **Contacts Manager (Map)**
Stores, searches, updates, and deletes contact information using key–value pairs.

* Data Structure: Map
* Concept: Fast lookup and structured records
* Use case: Address books, dictionaries

---
